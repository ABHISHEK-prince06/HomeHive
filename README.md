# HomeHive

HomeHive is a full-stack home services marketplace for customers and professionals.

## Features

- Customer search, filters, and map-based discovery
- Provider onboarding, verification, and dashboard
- Booking workflow with pricing transparency and availability checks
- Admin management for users, providers, services, and bookings

## Structure

- `client/` — React frontend
- `server/` — Node.js + Express backend

## Setup

1. Install dependencies for `server` and `client`
2. Create `.env` based on `.env.example`
3. Start MongoDB
4. Seed demo data
5. Run backend and frontend
